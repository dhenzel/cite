# cite-worker — hosted Cite v0: MCP endpoint + operator console

Cloudflare Worker serving:
- **`POST /mcp`** — the public free read tier (MCP Streamable HTTP): `search_sites`,
  `get_site`, `estimate`, `inventory_stats`. Whitelisted fields only — domains,
  contacts, seller prices, and markup are never serialized here (blind placements).
- **`/admin`** — the operator console (SPEC §16): full inventory table with
  per-site seller price, markup, computed listed price and margin, status,
  link-attribute backfill, add-site. Guarded by the `ADMIN_TOKEN` secret.
- Backing store: the `cite-v0` D1 database — edits in the console are live to
  buyers immediately, no redeploys for data.

## First-time setup (Worker must live in the SAME account as the cite-v0 D1)

```bash
cd cite-worker
npm install
# 1. load inventory (seed.sql generated by cite-mcp/src/export-seed.ts — never commit it)
npx wrangler d1 execute cite-v0 --remote --file=/path/to/seed.sql
# 2. set the operator token (pick something long and random)
npx wrangler secret put ADMIN_TOKEN
# 3. deploy
npx wrangler deploy
```

Then:
- Operator console: `https://<worker-url>/admin` (enter the token)
- Connect an agent: `claude mcp add --transport http cite https://<worker-url>/mcp`
  (or claude.ai → Settings → Connectors → custom connector with the `/mcp` URL)

## Reseeding / updating data in bulk

Regenerate from the local master DB (`cite-mcp`): `npx tsx src/export-seed.ts`,
then re-run the `d1 execute` command (the seed drops + recreates tables).
Per-site edits are better done in the console.

## Tests

`npx tsx scripts/worker-test-d1.mts` — runs the Worker handler against an
in-memory SQLite shim: public leak checks, admin auth, markup → listed-price
recompute, add-site, OAuth-discovery 404s.
