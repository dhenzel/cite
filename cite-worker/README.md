# cite-worker — hosted Cite v0 MCP endpoint

Cloudflare Worker serving the Cite free read tier over MCP Streamable HTTP.
The bundled dataset (`data/public-data.json`, generated by
`cite-mcp/src/export-public.ts`) contains PUBLIC fields only — anonymized
handles, Cite Scores, traffic bands, listed prices, scrubbed content
summaries. No domains, contacts, or seller prices exist in this deployment,
so the endpoint structurally cannot leak them.

## Deploy

```bash
cd cite-worker
npm install
npx wrangler deploy        # after `wrangler login`, deploys to your account
```

To refresh the dataset: rebuild the local DB (`cite-mcp`), run
`npx tsx cite-mcp/src/export-public.ts`, redeploy.

## Connect

```bash
claude mcp add --transport http cite https://<your-worker-url>/mcp
```

Or add it as a custom connector on claude.ai (Settings → Connectors → Add
custom connector → the /mcp URL).

Endpoints: `POST /mcp` (MCP), `GET /health`, `GET /` (info).

## v0 notes

- No auth and no rate limiting yet — fine for a private trial, add before
  sharing the URL anywhere public.
- `estimate` is the cold-start allocator sketch (per-placement cap, score
  bands); the real allocator lands with the funded tier.
